# Portfolio site

My personal portfolio: a small static site (plain HTML, CSS, and JavaScript, no build step) in English and French, with a project grid that fills itself from my public GitHub repositories.

## How projects get on the site

There are two kinds of cards, shown in this order:

1. **Curated cards**, written by hand in [`projects.js`](projects.js) with screenshots, a longer description, highlights, and a French translation.
2. **Automatic cards**, one for every other public repository, built by [`scripts/sync-repos.mjs`](scripts/sync-repos.mjs).

So when I make a new repository **public**, it appears on the site within a day (or right away if I run the workflow by hand). Nothing else to do.

An automatic card is built from the repository itself:

| Card part | Where it comes from |
| --- | --- |
| Title | The repository name |
| Description | The GitHub description, or the first paragraph of the README |
| Technology pills | The top languages, then the GitHub topics |
| Screenshot | The first image in `docs/screenshots/`, or GitHub's generated preview card |
| Details pop-up | The first paragraphs of the README, and all images in `docs/screenshots/` |
| Live link | The repository's homepage URL, if set |

To get a good automatic card: write a GitHub description, add topics, and put screenshots in `docs/screenshots/`.

**Leave a public repo off the site:** add the GitHub topic `no-portfolio`. Forks, archived repositories, and the site's own repository are always skipped.

**Upgrade an automatic card to a curated one:** copy a block in `projects.js` and keep its `code` link pointing at the repository. The automatic card is then dropped.

## The pipeline

The workflow in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) runs on every push to `main`, every day at about 06:17 UTC, and on demand (Actions tab, "Run workflow"). It runs the sync script, then publishes the site.

## Files

| File | Purpose |
| --- | --- |
| `index.html`, `styles.css`, `script.js` | The page, its style, and the rendering code |
| `i18n.js` | All page text in English and French |
| `projects.js` | Curated project cards and the skills list |
| `auto-projects.js` | Generated by the sync script (an empty list in the repository) |
| `scripts/sync-repos.mjs` | Reads my public repositories and builds the automatic cards |
| `resume.pdf` | Résumé (French) |

## Run it locally

```bash
python -m http.server 8123   # or: npx serve .
```

Open <http://localhost:8123>. To preview the automatic cards locally, run `node scripts/sync-repos.mjs` first (set `GITHUB_TOKEN` to avoid API rate limits).
